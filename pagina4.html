  • dominio:

    En informática, un dominio es la identificación única de un sitio web en Internet, también conocido como nombre de dominio. Es el nombre que se escribe en la barra de direcciones del navegador para acceder a una página web.

  • sub dominio

    s una extensión de tu dominio principal que te permite crear secciones o sitios web separados dentro de tu dominio principal

  • URL:

    URL significa Uniform Resource Locator (Localizador de Recursos Uniforme)

  • DNS:

    es el sistema que traduce nombres de dominio (como google.com) a direcciones IP numéricas

  • Hosting

    Un hosting es un servicio de alojamiento web que te permite publicar un sitio web o aplicación en Internet

  • FTP

    es un protocolo de red estándar utilizado para la transferencia de archivos de un host a otro a través de una red basada en TCP, como Internet.

  • HTTP

    es un protocolo de comunicación en internet que permite transferir información (como páginas web, imágenes, etc.) entre un servidor y un cliente
